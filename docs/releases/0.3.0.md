# Reference Library 0.3.0

**A calmer, more coherent editorial work surface.**

**Post-publication correction — 2026-08-30:** `v0.3.0` was published from commit `cd80a2dd6ef9a6fe0e4e5b84dafcd5fe8d295120` after the successful five-job exact-`main` CI run [#333](https://github.com/bomkino/reference-library/actions/runs/33293229006). This correction updates candidate-only status language; it does not change the release's feature history.

0.3.0 preserves the 0.2 editorial catalogue and decision loop while replacing the visual foundation. It changes no `.pitchlibrary` schema, protocol or canonical document meaning.

## Highlights

- PD Body is the default interface family, PD Head is reserved for major editorial display, and PD Eyebrow identifies literal metadata and compact data.
- All seven pitch.dog Type System v13 WOFF2 files are bundled locally under CC0, pinned to tag `v13.0.0` and commit `786b4a2b671182319320f922b8de8f927ea3a002`.
- Font rendering is deterministic and offline; the app never fetches a runtime font from GitHub or another service.
- Pinned Phosphor React icons replace improvised CSS masks and icon-like glyphs through one accessible wrapper.
- A shared eight-step spacing scale normalizes component insets, gaps, toolbar rhythm, panel padding and modal spacing.
- Ordinary controls remain at least `max(44px, 3.5rem)`; compact and icon-only targets remain at least `max(44px, 2.75rem)`.
- Narrow layouts retain Library and Inspector capability in explicit, focus-managed drawers.
- Existing interface scale, thumbnail density and Preview zoom remain independent.
- Exact-branch CI captures synthetic wide, medium, narrow and 80%/150% Interface Scale layouts, and fails on unloaded PD fonts, horizontal overflow, clipped controls or sub-44 px button/summary targets.

## Install

### macOS

Expand the ZIP, move `Reference Library.app` to `/Applications`, then Control-click it and choose **Open**. The app is ad-hoc signed but not notarized. Approve this exact app through Finder or **Privacy & Security**; do not disable Gatekeeper globally.

### Linux

- AppImage: mark executable and run.
- Arch/Garuda: install the `.pacman` artifact with `sudo pacman -U`.
- Portable: expand the tar archive and run the bundled executable.
