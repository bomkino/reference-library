# Reference Library 0.3.1

**Everything sits where it means to.**

0.3.1 is a visual-craft patch over 0.3.0. It refines alignment, containment and motion without changing `.pitchlibrary` schema, protocol or canonical document meaning.

## Highlights

- Icons, labels and carets sit on deliberate optical axes inside buttons, disclosure headers, toolbars, panels and drawers.
- Carets use a consistent size and breathing room before their labels.
- Button text and icons retain balanced internal padding, predictable gaps and stable heights.
- Panel and container insets hold a coherent rhythm across wide, medium and narrow layouts.
- Long labels and constrained content stay contained without horizontal page overflow or clipped actions.
- Drawers, filters and batch tools stay in stable overlay layers; local disclosures expand with measured motion instead of an abrupt jump.
- Transitions remain restrained and intent-led; reduced motion removes non-essential travel immediately.
- The pitch.dog Type System v13 font roles, pinned Phosphor icons and 44 px minimum interactive-target floor remain intact.

## Install

### macOS

Expand the ZIP, move `Reference Library.app` to `/Applications`, then Control-click it and choose **Open**. The app is ad-hoc signed but not notarized. Approve this exact app through Finder or **Privacy & Security**; do not disable Gatekeeper globally.

### Linux

- AppImage: mark executable and run.
- Arch/Garuda: install the `.pacman` artifact with `sudo pacman -U`.
- Portable: expand the tar archive and run the bundled executable.
