# Product Constitution

## Product sentence

Reference Library is a project-specific, private visual research and source-organising application that helps a person see, compare, curate, remember, safely manage and reuse material for a creative pitch deck.

It is not a decorated file index, archive administration system, cloud service or AI product.

## Founder locks

- pitch.dog is the first real user; each creative project gets one Library.
- Apple-Silicon macOS is primary, using SwiftUI and WebKit.
- Garuda Linux / Arch / KDE is the binding Linux target, using Electron.
- Both editions open the same neutral Library without semantic loss.
- No account, cloud dependency, telemetry, embedded AI, model download, generated tagging, semantic model search, automatic creative judgment or assistant pane.
- Creative decisions remain manual. Automation uses stable named commands and cannot bypass product policy.
- Sources remain in place by default. Missing or offline material retains its curation.
- Asset identity is independent of path, filename and content hash.
- Editorial Contact Sheet is the principal calm surface. Material dominates stable, restrained chrome.
- Motion requires user intent. No ambient grid-wide autoplay.
- Interface Scale is first-class and separate from thumbnail density and preview zoom.

## Values

Recognition before administration. Calm visual memory. Durable meaning over brittle location. Progressive usefulness. Honest capability states. Explicit, recoverable power. No false intelligence.

## Failure conditions

The product fails this constitution if paths become identity; browser storage becomes canonical; missing sources disappear; the workspace gains unrestricted filesystem/process/SQL access; platform documents diverge; source changes overwrite silently; panels jump with selection; unsupported formats vanish into logs; ambient motion takes over; or an AI/model becomes necessary.
