# Brutalist interface review

| Before | After | Why |
| --- | --- | --- |
| Small dashboard-like controls | 3.5 rem minimum control system | Default targets measure 52.5 px at 100% Interface Scale and remain usable as the sizing system changes. |
| Compact SaaS panel rhythm | Oversized editorial hierarchy and severe spacing | The contact sheet reads as a working publication surface rather than an administration console. |
| Soft card chrome | Thick near-black rules, square corners and hard offset shadows | Structure becomes legible without gradients, glass or decorative density. |
| Generic product mark | A reference frame occupied by an oversized dog, plus one coral registration point | The mark follows pitch.dog’s sparse ink, cool field, impossible relationship and restrained-accent law. |
| Interface Scale treated as a cosmetic preference | Root typography, controls, spacing and panel geometry scale together | This matches Figma-like interface scaling while keeping thumbnail density and Preview zoom independent. |
| Inspector sacrificed at narrower widths | Inspector reflows below the contact sheet, then stacks | Editing continuity matters more than preserving one desktop grid. |
| Ambient UI animation | Immediate state changes, short pointer feedback and reduced-motion compliance | Frequent editorial and keyboard actions stay fast; motion serves feedback only. |

Promotion requires the existing keyboard, stale-state, modal, 100,000-Asset, Rust, Linux package/runtime and macOS package gates. This review does not replace those proofs.
