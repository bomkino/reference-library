# ADR-005 — Editorial Contact Sheet Is the Default Workspace

**Status:** Accepted  
**Date:** 26 August 2026

## Decision

Editorial Contact Sheet is the resting workspace. Working Table may become an explicit dense metadata mode; Project Room may influence grouped Collection projections. Neither replaces the default or becomes a dashboard/freeform canvas.

Project imagery dominates stable, quiet chrome. Cards remain static at rest. Selection, review and errors never alter geometry.
